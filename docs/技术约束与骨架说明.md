## 五、核心流程（唯一入口）

### 5.1 审核主流程（必须统一）

```csharp
public async Task<AuditResult> RunAudit(AuditRequest request)
{
    // 1. Excel预校验（阻断）
    ValidateExcel(request.ExcelPath);

    // 2. 加载模板
    var template = LoadTemplate(request.TemplatePath);

    // 3. 并发处理图片
    var imageResults = await ProcessImagesAsync(request.ImagesPath, template);

    // 4. 匹配逻辑
    var matched = MatchWithExcel(imageResults, request.ExcelData);

    // 5. 重复检测
    DetectDuplicate(matched);

    // 6. 汇总结果
    var result = BuildResult(matched);

    // 7. 输出报告
    ExportReport(result);

    return result;
}
```

---

### 5.2 强制约束

```text
✔ 所有审核逻辑必须从 RunAudit 进入
❌ 禁止在 UI 层直接调用 Core 逻辑
```

## 六、并发模型（锁死实现方式）

### 6.1 并发策略

```text
线程数 = CPU核心数 - 1
最小线程数 = 1
```

---

### 6.2 实现方式（强制）

```csharp
SemaphoreSlim semaphore = new(maxConcurrency);

var tasks = images.Select(async img =>
{
    await semaphore.WaitAsync();
    try
    {
        return await ProcessImage(img);
    }
    finally
    {
        semaphore.Release();
    }
});

await Task.WhenAll(tasks);
```

---

### 6.3 禁止项

```text
❌ 禁止使用 Thread 手动管理
❌ 禁止使用 Parallel.ForEach
```
